# Flowbill CRM — รุ่นเริ่มต้น

เว็บแอปต้นแบบสำหรับจัดการลูกค้า สินค้า/ขนาด/ราคา และใบเสนอราคา

## เปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที ข้อมูลตัวอย่างและข้อมูลที่เพิ่มจะบันทึกในเบราว์เซอร์ของเครื่องนั้น

## นำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. เปิด **Settings → Pages** ของ repository
3. เลือก Deploy from a branch และเลือก branch `main` ที่ root
4. GitHub จะสร้างลิงก์เว็บให้ภายในไม่กี่นาที

## ขั้นถัดไปที่แนะนำ

ย้ายข้อมูลจาก Local Storage ไปยัง Supabase, เพิ่มการล็อกอิน, เพิ่มรายการสินค้าในใบเสนอราคา และสร้าง PDF สำหรับใบเสนอราคา/ใบวางบิล/ใบกำกับภาษี

โครงสร้างฐานข้อมูลที่พร้อมนำเข้าอยู่ที่ `supabase/schema.sql` และคู่มือการตั้งค่าอยู่ที่ `supabase/SETUP.md`
